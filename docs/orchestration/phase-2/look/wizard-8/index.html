The result and the Send step beside the mockup

Each pair is the mockup's whole panel (left) and the built page's (right) at the same width, in the same state. The built page draws a real sliced file of two real parts; the mockup draws its own fake slice of its own parts, so the toolpaths and the figures differ. Phase 2's Send step has no printer: no printer's name, no plate-clear line, no caret and no printer-status icon. Made by make -C wizard look-result-send.
