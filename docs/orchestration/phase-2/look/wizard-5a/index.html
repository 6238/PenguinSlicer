The Settings step and advanced mode beside the mockup

Each pair is the mockup's whole panel (left) and the built page's (right) at the same width, in the same state. The built page is given a configuration and a table of settings made from the mockup's own sample of settings and profiles. Made by make -C wizard look-settings-step.
